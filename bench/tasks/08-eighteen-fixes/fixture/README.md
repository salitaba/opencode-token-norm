# checkout: eighteen independent bugs

Each file exports one function with one bug. The contract:

- `f01.countWords(s) — whitespace-separated word count, 0 for blank input`
- `f02.firstTruthy(values) — first truthy value, else null`
- `f03.arrayMax(nums) — largest value`
- `f04.arrayMin(nums) — smallest value`
- `f05.arraySum(nums) — sum; 0 for an empty array`
- `f06.productAll(nums) — product; 1 for an empty array`
- `f07.countTruthy(values) — number of truthy values`
- `f08.allEven(nums) — true when every value is even`
- `f09.anyOdd(nums) — true when at least one value is odd`
- `f10.indexOfMin(nums) — index of the first smallest value`
- `f11.take(q) — first q.n values of q.values`
- `f12.drop(q) — q.values without its first q.n values`
- `f13.pairwiseSum(nums) — sums of adjacent pairs`
- `f14.interleave(a, b) — alternate values, extras appended in order`
- `f15.entriesToObject(q) — object built from q.pairs`
- `f16.repeatArray(q) — q.values repeated q.n times`
- `f17.maxByLength(q) — longest word, first one on ties`
- `f18.rotateLeft(nums) — move the first value to the end`
