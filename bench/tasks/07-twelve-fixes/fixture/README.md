# checkout: twelve independent bugs

Each file exports one function with one bug. The contract:

- `f01.capitalize(s) — trim, then uppercase only the first letter`
- `f02.indexOfMax(nums) — index of the first largest value`
- `f03.sumTo(n) — sum of 1..n inclusive`
- `f04.repeatStr(q) — q.s repeated q.n times`
- `f05.countOccurrences(q) — non-overlapping count of q.sub in q.s`
- `f06.removeFalsy(values) — drop all falsy values`
- `f07.endsWithVowel(s) — true when the trimmed string's last letter is a vowel`
- `f08.powInt(q) — q.base raised to the integer q.exp`
- `f09.lastWordLength(s) — length of the final whitespace-separated word`
- `f10.rangeExclusive(q) — integers q.start..q.end-1`
- `f11.zip(a, b) — pairs up to the shorter length`
- `f12.toggleCase(s) — swap upper/lower case per character`
